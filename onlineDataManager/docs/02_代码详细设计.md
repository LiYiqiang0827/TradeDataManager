              │    └─ from core.logger import setup_logger
              │
              └─ service_check_*.py (2 个,v6.7 新增 — 检查工具,不进 plist)
                   ├─ service_check_redis.py → core.check_redis (13 个 check 函数)

test 层(独立进程,直接调 core + service)
  ├─ test_checkredis_*.py → core.check_redis / core.redis_online
  ├─ test_checkdb_*.py    → core.check_db    / core.sqlite_client

  └─ service_check_*.py   → core.check_redis / core.check_db(v6.7 新增,debug + cron 体检用)

### 4.2 scheduler_onlineData 详解

**核心数据结构**(实际代码名,2026-09-16 v6.15 校正):
- **`WRITER_PHASE_SERVICES` / `SAVEDATA_PHASE_SERVICES`**:phase → service 列表映射(注:`WRITER_SERVICES` / `SAVEDATA_SERVICES` / `PHASES` 这三个名字**不存在于代码**,勿误抄)
- `WRITER_PHASES` / `SAVEDATA_PHASES`:**10 个时间阶段名**(WRITER × SAVEDATA 二维,v6.15 加 `idle_pre_morning` / `idle_pre_afternoon`)
- `WRITER_DAEMONS_MORNING_AFTERNOON` / `SAVEDATA_DAEMONS_MORNING_AFTERNOON`:早上/下午持续跑的常驻 daemon 列表
  - **WRITER_DAEMONS_MORNING_AFTERNOON** = 8 个(删 orderbook,加 snapshot_index):`snapshot / snapshot_index / minute / zt / break / anomaly / hot / limitperformance`
  - **SAVEDATA_DAEMONS_MORNING_AFTERNOON** = 8 个(删 savedata_orderbook,加 savedata_snapshot_index):同 8 个 savedata 版
- `spawn_service(name: str, args: list[str], *, log: logging.Logger, timeout_sec: int = 300) -> int`:同步启动一个 service 子进程,返回 rc(`--once` 模式同步等子进程跑完,非 --once 模式异步 Popen 立即返回 0)

**主循环**(`main()`):
```
while True:
    now = datetime.now().time()
    phase = match_phase(now)
    if phase != current_phase:
        kill_all_running_services()
        start_services_for_phase(phase)
        current_phase = phase
    sleep 60
```

**WRITER × SAVEDATA 各 10 个阶段**(`WRITER_PHASES` / `SAVEDATA_PHASES` 真值,见 `代码详细设计/scheduler_onlineData.md §2.1`):

### 4.3 scheduler_once 详解

**CLI 接口**:
```bash
python3 -m scheduler.scheduler_once                          # 跑全部 20 个
python3 -m scheduler.scheduler_once --only writer           # 只跑 writer
python3 -m scheduler.scheduler_once --only savedata         # 只跑 savedata
python3 -m scheduler.scheduler_once --only snapshot         # 只跑某个 kind
python3 -m scheduler.scheduler_once --skip auction,break    # 跳过某些
```

**核心逻辑**:
- 复用 `scheduler_onlineData.spawn_service()`
- 每个 service 单独 `subprocess.run([...], timeout=180)`
- 跑完打印 summary 表(OK/FAIL/TIMEOUT/SKIP + 耗时)
- **不入 plist**,纯 CLI 调试工具

## §6 调用关系示例

### 6.1 一次"拉快照 → 写 Redis → 落 SQLite"的完整调用链

```
scheduler_onlineData.spawn_service(name="service_writeredis_snapshot", args=[], log=...)
  └─ subprocess.Popen(["/opt/anaconda3/bin/python3", "-u", "-m", "service.service_writeredis_snapshot", ...])
        └─ OnlineRedis()                                      # core.redis_online
        └─ from coreClient.ths_client import fetch_snapshots  # 同花顺 CLI(不是 TdxClient)
        └─ r.get_watchlist()
        └─ fetch_snapshots(watchlist)                         # 同花顺
        └─ r.put_snapshots_batch([(ts_code, data), ...])      # pipeline 写 STREAM + ZSET window(无 HSET,无 commit_snapshots_batch)
        └─ (timeline + archive 由 v6.3 客户端可选,本轮非必要)
        └─ sleep 6 秒,下一轮

[30秒后,落盘端启动]

scheduler_onlineData.spawn_service("service_savedata_snapshot")
  └─ subprocess.Popen(["python3", "-m", "service.service_savedata_snapshot"])
        └─ ServiceSavedataSnapshot(SavedataDaemon)
        └─ _do_persist() → persist_kind(r, *, kind="snapshot", trade_date=td)   # core.persist_client
              ├─ connect(ym) → conn                                              # core.sqlite_client 内部 connect
              ├─ _get_cursor(r, conn, "snapshot") → last_id                     # 从 online_stream_cursor 表读游标
              ├─ XREAD > last_id (count=STREAM_BATCH=1000)                       # 读 STREAM 新数据
              ├─ for msg: _extract_snapshot_row(msg, *, trade_date, now_save="")   # 真签名
              ├─ insert_snapshots_batch(conn, *, kind="snapshot", trade_date=td, snapshots=rows)   # executemany + commit
              ├─ update_cursor(conn, *, stream_key=..., last_id=max_id, trade_date=td)   # 推进游标 + 内部 commit
              └─ return inserted                                                # 不显式 conn.commit()(依赖 update_cursor 内部 commit)
```
