## 命名规则

- **主文档**:NN_<标题>.md(NN = 01-06 编号)
- **CHANGELOG**:NN_<标题>_CHANGELOG.md(在 `修改记录/` 下)

## 写入规范(2026-09-16 拍板)

1. **每次主文档改完必须同步追加 CHANGELOG**(否则违反"文档与代码一致"原则)
2. CHANGELOG **按版本号倒序追加**(新版本在文件底部)
3. 每个版本号必须含:**触发 / 改动清单 / 原因 / 影响(生产/只是文档)**
4. **历史条目不允许修改**(保留作为变更快照)
5. **CHANGELOG 文末无需单独"目录索引"**(本 README 就是索引)

## 阅读建议

- 看最近 1-2 个版本 → 当前状态
- 看全版本 → 演进轨迹(架构 / 数据 / 频率 / kind 增减)
- 看 trigger / 影响 → 判断风险等级(生产代码改动 / 纯文档 / 注释调整)
