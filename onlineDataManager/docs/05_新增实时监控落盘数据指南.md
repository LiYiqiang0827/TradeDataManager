## §4 Redis 三件套设计(STREAM + timeline + archive + window)

### 4.1 四个 key 命名规范

```python
# scripts/core/redis_online.py 顶部
_k("xxx", "stream")      # online:xxx:stream         STREAM,落盘主数据源
_k("xxx", "timeline")    # online:xxx:timeline       ZSET,archive_key → unix_score
_k("xxx", "archive", ts) # online:xxx:archive:{ts}   HASH,某 ts 全市场快照
_k("xxx", "window", code)# online:xxx:window:{ts_code} ZSET,单股滑窗(实时)
```

`_k(kind, *parts)` 是基类方法,生成 `online:<kind>:<parts>` 形式(参考 `redis_online.py` 现有写法)。

### 4.2 三件套写入流程

**核心思想**:每个 kind 必须支持两个动作 — **put**(批量写单股实时 + 单股滑窗) + **commit**(一轮末尾写全市场快照)。

```
每 1 分钟 tick:
  writeredis_xxx --once
    ├─→ r.put_xxx_batch(items)     # 1 次 pipeline,全市场 N 股
    │     ├─→ STREAM XADD online:xxx:stream (单股 1 条)
    │     ├─→ ZADD online:xxx:window:{ts_code} (单股滑窗)
    │     └─→ EXPIRE window_key WINDOW_TTL_xxx
    │
    └─→ r.commit_xxx_batch(items)  # 1 次 pipeline,全市场 1 个 archive
          ├─→ HSET online:xxx:archive:{unix_ms} {ts_code_1: data_1, ...}
          ├─→ EXPIRE archive_key ttl(动态 / 12h)
          ├─→ ZADD online:xxx:timeline {archive_key: unix_score}
          └─→ EXPIRE timeline_key TIMELINE_TTL_xxx
```

### 4.3 滑窗裁剪(可选,推荐)

落盘后再裁剪 timeline + 删旧 archive:

```python
# 在 commit_xxx_batch 里,pipeline 外单独 read(因 pipeline 不能有 read 命令)
cutoff = now_unix - slide_window
old_keys = self.r.zrangebyscore(timeline_key, "-inf", f"({cutoff}")
if old_keys:
    self.r.zremrangebyscore(timeline_key, "-inf", f"({cutoff}")
    if old_keys:
        self.r.delete(*old_keys)
```

### 4.4 TTL 拍板

| key | TTL 类型 | 拍板原则 |
|---|---|---|
| `online:xxx:stream` | 固定(STREAM_TTL = 12h)| 全局统一,看 `redis_online.py` 顶部常量 |
| `online:xxx:window:{ts_code}` | 固定(WINDOW_TTL_xxx)| 单股滑窗 12h 兜底 |
| `online:xxx:timeline` | 固定(TIMELINE_TTL_xxx = 12h)| 全局兜底 |
| `online:xxx:archive:{ts}` | **动态**(参见 [02_代码详细设计 §6](02_代码详细设计.md))| 11:00-11:30 用 7200s,其余 1800s(snapshot 已用此模式)|

**拍板原则**:**动态 > 写死**(参见 memory 2026-09-14 Q2 拍板原则)。如果业务节奏允许,archive TTL 优先用"根据写入时间点实时算"。

## §5 redis_online 接口新增规范

### 5.1 必须新增的方法(3 个一组)

每个新实时监控 kind,在 `core/redis_online.py` 的子类(如 `OnlineRedis`)下加 **3 个方法**:

| 方法 | 作用 | 返回 |
|---|---|---|
| `put_xxx_batch(items)` | 批量写 STREAM + 单股 window | `int` 写入股票数 |
| `commit_xxx_batch(items)` | 一轮末尾写全市场 archive + timeline | `str | None` archive_key |
| `get_xxx_timeline(count=N)` | 读 timeline(下游 check 工具用) | `list[dict]` |

### 5.2 put_xxx_batch 真值模板(参考 `put_snapshots_batch` L521)

```python
def put_big_order_batch(self, items: list[dict]) -> int:
    """批量写大单明细
    
    Args:
        items: [{"ts_code": "600000.SH", "data_timestamp": ..., "amount": ..., ...}, ...]
    
    Returns:
        实际写入的股票数(过滤空 ts_code)
    """
    if not items:
        return 0
    
    stream_key = _k("big_order", "stream")
    pipe = self.r.pipeline()
    written = 0
    fields_list = []
    
    for item in items:
        ts_code = item.get("ts_code")
        if not ts_code:
            continue
        
        ts_ms = int(item.get("data_timestamp", time.time() * 1000))
        score = float(ts_ms) / 1000.0
        
        # flat_record:基类方法,把 item 扁平化成 STREAM fields
        flat = self._flat_record(
            ts_code, item,
            drop_keys=DEFAULT_DROP_KEYS,
            ts_field="data_timestamp", ts_value=ts_ms,
        )
        fields_list.append(flat)
        
        # window:{ts_code} 单股滑窗
        window_member = self._encode({"ts_code": ts_code, **item})
        window_key = _k("big_order", "window", ts_code)
        self._slide_zset_window(pipe, window_key, {window_member: score}, ttl=WINDOW_TTL_BIG_ORDER)
        written += 1
    
    # 批量 STREAM 写入(基类方法)
    self._xadd_many(
        pipe, stream_key, fields_list,
        maxlen=STREAM_MAXLEN_BIG_ORDER, ttl=STREAM_TTL,
    )
    pipe.execute()
    return written
```

### 5.3 commit_xxx_batch 真值模板(参考 `commit_snapshots_batch` L568)

```python
def commit_big_order_batch(self, items: list[dict], now_dt=None) -> str | None:
    """一轮末尾写全市场大单 archive + timeline"""
    if not items:
        return None
    
    now_dt = now_dt or datetime.now()
    now_unix = now_dt.timestamp()
    ttl = calc_big_order_archive_ttl(now_dt)   # 动态 TTL 函数(可选)
    slide_n = calc_big_order_slide_window(now_dt)  # 滑窗裁剪窗口
    ms = int((now_unix - int(now_unix)) * 1000)
    archive_key = _k("big_order", "archive", f"{int(now_unix)}.{ms:03d}")
    timeline_key = _k("big_order", "timeline")
    
    # 全部 item HSET 进同一个 archive_key
    mapping = {item["ts_code"]: self._encode(item) for item in items if item.get("ts_code")}
    if not mapping:
        return None
    
    pipe = self.r.pipeline()
    pipe.hset(archive_key, mapping=mapping)
    pipe.expire(archive_key, ttl)
    pipe.zadd(timeline_key, {archive_key: now_unix})
    pipe.expire(timeline_key, BIG_ORDER_TIMELINE_TTL)
    pipe.execute()
    
    # 滑窗裁剪(放 pipeline 外,因为 read 命令阻塞)
    cutoff = now_unix - slide_n
    old_keys = self.r.zrangebyscore(timeline_key, "-inf", f"({cutoff}")
    if old_keys:
        self.r.zremrangebyscore(timeline_key, "-inf", f"({cutoff}")
        if old_keys:
            self.r.delete(*old_keys)
    return archive_key
```

### 5.4 get_xxx_timeline 真值模板(参考 `get_snapshot_timeline`)

```python
def get_big_order_timeline(self, count: int = 50) -> list[dict]:
    """读 big_order 全市场时间线(返回最近 N 个 archive_key)"""
    timeline_key = _k("big_order", "timeline")
    keys = self.r.zrevrange(timeline_key, 0, count - 1)
    return [
        {
            "archive_key": k.decode() if isinstance(k, bytes) else k,
            "ts": int(k.decode().split(":")[-1].split(".")[0]) if isinstance(k, bytes)
                  else int(k.split(":")[-1].split(".")[0])
        }
        for k in keys
    ]
```

### 5.5 强制规则

- **统一 encode/decode**:必须用 `self._encode(item)` / `self._decode(v)` 基类方法,不要自己 `json.dumps`
- **Redis pipeline 不能有 read 命令**:read 必须单独 `self.r.xxx()`,放 `pipe.execute()` 之后
- **每个方法必须有 docstring + Args + Returns**(便于 AI 检查)
- **STREAM maxlen 必须配**(防止爆内存,参考 `STREAM_MAXLEN_xxx` 常量)

## §7 落盘链路(persist_xxx)

### 7.1 在 `core/persist_client.py` 新加函数

```python
# scripts/core/persist_client.py
def persist_snapshot_index(
    redis_client: OnlineRedis,
    *,
    trade_date: str,
) -> int:
    """读 STREAM 增量落盘 snapshot_index

    Args:
        redis_client: redis_online 客户端
        trade_date: YYYY-MM-DD(落盘哪个交易日)

    Returns:
        本次落盘行数
    """
    stream_key = _k("snapshot_index", "stream")
    cursor = read_cursor(stream_key)
    last_id = cursor.get("last_id", "0-0") if cursor else "0-0"

    # 读 STREAM(从 last_id 开始)
    new_entries = redis_client.r.xread({stream_key: last_id}, block=0, count=1000)
    if not new_entries:
        return 0

    # 转 SQL + 批量 INSERT
    rows = []
    latest_id = last_id
    for _stream, entries in new_entries:
        for entry_id, fields in entries:
            decoded = {k.decode() if isinstance(k, bytes) else k:
                       v.decode() if isinstance(v, bytes) else v
                       for k, v in fields.items()}
            rows.append(_to_snapshot_index_row(decoded, trade_date))
            latest_id = entry_id.decode() if isinstance(entry_id, bytes) else entry_id

    # 批量 INSERT
    conn = sqlite_client.get_conn(trade_date[:6])
    try:
        conn.executemany("INSERT OR REPLACE INTO tbl_snapshot_index ...", rows)
        conn.commit()
        # commit 后才推游标(v1.23 修复:失败返回 -1 不推进)
        update_cursor(stream_key, latest_id, trade_date)
        return len(rows)
    except Exception as e:
        log.error(f"persist_snapshot_index 失败: {e}")
        return -1
```

### 7.3 强制规则(v1.23 已修)

| 规则 | 原因 |
|---|---|
| **commit 后才推游标** | 落盘失败返回 -1,不推进游标,下次重启能重试 |
| **落盘失败单条不影响其他** | 游标只在全部 commit 后推进 |
| **`data_timestamp` 内部全 `YYYY-MM-DD HH:MM:SS.fff`** | v3 双时间戳原则 |
| **stale 过滤** | 只落 `trade_date == 今天` 的数据,跨日数据丢弃 |

```python
# scripts/service/service_writeredis_snapshot_index.py
"""实时监控:8 只固定指数快照写入 daemon(v6.10)"""
import argparse, sys, time
from core.logger import get_logger
from coreClient.ths_client import fetch_index_snapshot
from core.redis_online import OnlineRedis

log = get_logger("service_writeredis_snapshot_index")


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--once", action="store_true", help="跑一轮就退")
    parser.add_argument("--interval", type=int, default=10, help="扫描间隔(秒,v6.15 原 30s)")
    args = parser.parse_args()

    r = OnlineRedis()
    while True:
        try:
            items = fetch_index_snapshot()           # 8 只指数
            if items:
                written = r.put_snapshot_index(items)  # STREAM + window
                archive_key = r.commit_snapshot_index(items)  # archive + timeline + 滑窗裁剪
                log.info(f"snapshot_index: {written} 只指数, archive={archive_key}")
        except Exception as e:
            log.error(f"snapshot_index 写入失败: {e}")

        if args.once:
            break
        time.sleep(args.interval)


if __name__ == "__main__":
    main()
```
