> **SQLite 表 + Redis key 的字段定义、写入读取脚本、SQL ↔ Redis 关系**
> **受众**:AI 改 schema、写查询、读落盘数据时
> **加新实时监控落盘数据**?→ 直接看 [05_新增实时监控落盘数据指南.md](05_新增实时监控落盘数据指南.md)(v1.0,2026-09-15 新增)的 §6 (SQLite schema 新增)+ §4 (Redis 三件套设计)+ §5 (redis_online 接口规范)。
> **v6.10 新增(2026-09-16)**:**snapshot_index** — 8 只固定指数(30s/轮)的快照落盘表 `snapshot_index_YYYYMMDD`,字段 15 列,沿用 snapshot 表结构 + `snapshot_unix` 替代 `lu_time`(指数无涨停时间)。详见 §X snapshot_index。
> **全局时间戳精度(v1.4 新增)**:**所有 `<kind>_timestamp` / `created_at` / `updated_at` 一律精确到毫秒(3 位)**。格式:
> - **数据时间戳**(`<kind>_timestamp` / `data_timestamp`):`YYYY-MM-DDTHH:MM:SS.fff`,由 `persist_client._stamp_stream_field()` 自动判断上游精度(ms int 转 ms,s float 转 ms);上游 KPL/THS 给秒时,落盘时补 `time.time()` 当时的毫秒。
> - **落盘时间戳**(`created_at` / `updated_at`):`YYYY-MM-DD HH:MM:SS.fff`,SQLite `DEFAULT strftime('%Y-%m-%d %H:%M:%f','now','localtime')`(SQLite ≥3.20,本机 3.45.3 ✅);Python 端写则用 `datetime.now().isoformat(timespec="milliseconds")`。
> - **保留例外**:`watchlist.lu_time` / `limitperformance.lu_time` 仍是 int64 unix(涨停时间,不能丢精度)。
> - **向后兼容**:`datetime.fromisoformat()` 自动解析秒 + 毫秒两种 ISO,2026-09-15 之前的老数据(秒级)仍可被查询正常解析;新数据全部毫秒。

```sql
CREATE TABLE online_stream_cursor (
    stream_key    TEXT PRIMARY KEY,

    updated_at    TEXT,        -- 游标更新时间 ISO
    created_at    TEXT         -- 创建时间 ISO
);
```

#### `online_meta`(模块全局元数据)

```sql
CREATE TABLE online_meta (
    key    TEXT PRIMARY KEY,
    value  TEXT                 -- JSON
);
```

## §4 SQL ↔ Redis 关系

| Redis 数据来源 | SQLite 落盘 |
|---|---|
| `online:{kind}:stream` (STREAM) | `persist_kind` 读取 STREAM,INSERT 到 `{kind}_YYYYMMDD` |
| `online:{kind}:timeline` + `archive:{unix_ts}` | **不落盘**,查询层用 |
| `online:minute:{ts_code}` (ZSET) | `persist_minute` ZRANGE,INSERT 到 `minute_YYYYMMDD` |
| `online:orderbook:stream` (STREAM) | `persist_kind` → `persist_stream_kind(kind="orderbook")` 读 STREAM,INSERT 到 `orderbook_YYYYMMDD` |
| `online:orderbook:window:{ts_code}` (ZSET) | **不落盘**,只是查询侧滑窗视图(查近 3.5 分钟 orderbook 用) |

**关键**:
- **落盘只看 STREAM / ZSET**(数据源)
- **timeline + archive 只是查询视图**,落盘无关
- STREAM 游标持久化在 SQLite 的 `online_stream_cursor` 表
